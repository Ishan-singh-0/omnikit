Score is the sum of active rules, capped at 100: 25 caution, 50 danger, 80 critical. A moving unit with no GPS altitude can only raise a low-confidence storm caution, never a danger.



Connect hardware
The simulation stops as soon as real packets arrive.


Point your ESP32 at this site
Open the Serial Monitor (115200 baud, newline) and type these lines. Values are saved in flash, no reflash needed.
Sign in and add a node to see its device key here.


USB, no radio or SIM needed
Flash esp32_gateway.ino and plug the ESP32 into this computer: it prints one JSON line every two seconds. Open this page from your relay (http://localhost:8080) in Chrome or Edge, then connect.


Cellular, the full chain
  • Run node server.js on a public host, create an account, add a device, paste its key into the sketch or type key … in the Serial Monitor.
  • Set the SIM’s APN and the relay URL (plain http://), power the SIM800L from its own 2 A supply.
  • Optional: set ALERT_WEBHOOK or TELEGRAM_TOKEN + TELEGRAM_CHAT and the relay sends the rescue brief by itself on danger or critical.


Test the pipeline without hardware
With the relay running, this fakes an SOS from a device:
curl -X POST "http://HOST:8080/ingest?key=DEVICE_KEY" -d '{"t":14,"h":80,"p":790,"lat":32.25,"lon":76.33,"alt":1960,"flags":32}'
